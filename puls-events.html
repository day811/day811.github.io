// 04 — fonctionnalités
MVP

Ce que le chatbot sait faire

🧠
Recherche hybride sémantique + temporelle
Comprend "ce weekend à Montpellier" ou "un concert de jazz la semaine prochaine". Filtre OData sur les métadonnées pour garantir 100% de résultats dans la fenêtre demandée.
🌐
Fallback recherche web (smolagents)
Quand l'index Azure AI Search retourne zéro résultat, un agent smolagents déclenche automatiquement une recherche DuckDuckGo restreinte à une whitelist de 10 sites événementiels français — billetweb, eventbrite, openagenda, fnacspectacles… Initialisation lazy pour ne pas impacter le démarrage.
💬
Mémoire conversationnelle
Historique des échanges persisté en PostgreSQL via Chainlit. Condensation automatique des questions de suivi en requêtes autonomes pour le retrieval.
📍
Contexte géographique personnalisé
Chaque utilisateur configure sa ville et son département par défaut. Le parser extrait les entités géographiques des requêtes et les priorise sur les préférences.
🔄
Ingestion incrémentale automatique
Container App Job déclenché chaque nuit à 3h. Stratégie high-watermark sur updatedAt. Upsert atomique dans Azure AI Search. Pipeline Bronze → Silver → Gold.
🔐
Authentification sécurisée
Comptes utilisateurs stockés dans Cosmos DB avec mots de passe hashés (bcrypt). Login natif Chainlit. Quotas tokens et questions configurables par utilisateur.
📡
Monitoring Grafana Cloud
Stack de monitoring complète sur tier gratuit Grafana Cloud. Deux datasources : Azure Monitor (CPU, mémoire, replicas — dashboards 16591/16592) et PostgreSQL custom (satisfaction 👍👎, latences RAG par phase, runs ingesteur, snapshots infrastructure Bronze/Silver/Gold).
📊
Télémétrie RAG détaillée
Chaque requête enregistre en PostgreSQL les latences par phase (condensation, search, génération), le nombre de candidats récupérés et filtrés, et le flag zéro-résultat déclencheur du fallback web.
// 05 — stack technique
choix justifiés

Technologies utilisées

Composant Technologie Justification
Interface conversationnelle Chainlit Streaming natif, gestion historique, login intégré — aucun dev front requis
API backend FastAPI + uvicorn Async natif, typage Pydantic, healthcheck Docker
Moteur RAG LangChain Abstraction LLM/vectorstore, support Azure et local (FAISS) sans changement de code
Index vectoriel Azure AI Search Recherche hybride (BM25 + vecteur) + filtres OData sur métadonnées temporelles
LLM Azure OpenAI GPT-4o Déploiement managé Azure, conformité RGPD, streaming async
Embeddings text-embedding-3-small Rapport qualité/coût optimal, 1536 dimensions
Fallback web smolagents + DuckDuckGo Agent CodeAgent déclenché si index retourne 0 résultat — whitelist 10 sites événementiels FR
Mémoire utilisateurs Cosmos DB NoSQL schemaless, latence faible, SLA 99.99%
Historique + télémétrie PostgreSQL (Flexible Server) Data layer Chainlit + tables monitoring rag_telemetry, ingestor_runs, feedbacks
Stockage pipeline Azure Blob Storage Bronze/Silver/Gold — pattern médaillon, coût minimal
Monitoring Grafana Cloud + asyncpg Tier gratuit — datasources Azure Monitor (Container Apps) + PostgreSQL custom
Déploiement Azure Container Apps Scale-to-zero, ingestion en Job schedulé, no k8s overhead
